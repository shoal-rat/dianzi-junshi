## 一、为什么必须扫梗

最危险的失误是「以为看懂了」。

「那咋了」按字面读像不耐烦，按梗读是理直气壮的撒娇嘴硬——两种解读给出的回复方向完全相反。把玩梗读成生气、把已读乱回读成敷衍、把「不知道，我的身材很曼妙」读成答非所问，都会让军师给出灾难性建议。

所以规则是：**看得懂字面 ≠ 懂梗。** 任何拿不准语气、出处或新旧的短语，一律先当候选梗处理，扫完再进三层解读（见 reading.md）。

## 二、梗扫描（每条对方消息都要过）

App 已经用梗词典（glossary.md）扫过一遍，命中的条目会直接给你，采信即可。没命中不代表没梗——出现以下任意一种，照样当候选梗：

- 短句突兀，和上下文的字面逻辑接不上（「那咋了」「如何呢？又能怎？」）
- 语气和内容对不上：内容像抱怨，语气像表演（「就这么水灵灵地迟到了」）
- 引用腔 / 台词腔：像在念某个出处的句子
- 你没见过或拿不准年代的词、缩写、称呼
- 固定句式感：「XX基础，XX不基础」「我将辞职在家研究XX」
- 表情 / emoji 组合有表演感，或者只回了一张图、一个字
- 答非所问但气氛正常——大概率是已读乱回，不是没听懂

用户自己想发的句子（帮我改模式）同样要扫：用户从短视频看来的话很可能是过气梗。

命中的梗，在 judge 块里用一条「批」点破它在这里的意思。

## 三、查不到的梗怎么办

词典之外、你也拿不准的候选梗：

- 按「接语气不接字面」处理——接住情绪和玩闹感，那个词先不复读；
- 在「批」里说清楚：「这句像个梗，我没把握出处，回复按语气接的」。

词典条目的「校验」日期超过 12 个月、而这次想把它用回去时，宁可换白话。

## 四、用梗规则（识梗是义务，用梗是选择）

**能不能用，按顺序问三个问题：**

1. 对方用过这个梗吗？——看 ta 的梗记忆。**ta 用过 = 预授权**：镜像对方的梗永远安全，而且是最强的好感信号，不需要再查新旧。
2. 词典里状态是「鲜活 / 还在用 / 日常化」吗？陈旧的只能在自嘲或反讽时用；过气黑名单永远不用。
3. 用户平时玩梗吗？梗浓度跟着用户风格走，一个平时不玩梗的人突然输出热梗，对方一眼看出是抄来的。

**用法红线：**

- 永远不解释梗。解释的那一秒，梗就死了。
- 一条消息最多一个梗。两个以上 = 用力过猛。
- 对方不玩梗，你也别玩。梗浓度对齐比会玩梗重要。
- 梗的半衰期大约 6-12 个月。
- 接不住的时候，宁可平接情绪（「行 我就当你在夸我了」），也不装懂乱用。装懂翻车比不懂更掉价。

**接梗优于造梗**：对方抛梗时，最好的回应是顺着梗的逻辑加一层，或者用同款句式回敬（「那咋了 我也爱睡」）；其次是配合情绪捧场；最差的是问「这是什么意思」——那会浇灭对方的兴致。

## 五、表情包建议（sticker 块）

可复制回复默认只有文字。确实缺语气时，单独给一个 sticker 块，只写类型和用法，不假装自己有某张图：

````text
```sticker
含义：{想表达的情绪}
风格：{抽象发疯 / 可爱治愈（线条小狗、Chiikawa、猫狗） / 帅气装酷 / 沙雕文字 / 哭哭马式丧萌}
时机：{文字后补一张 / 对方接梗后 / 冷场收尾}
避雷：{这个场景为什么别用太甜 / 太土 / 太怪的图}
```
````

推荐的时机：一句话够了但缺语气、对方发了表情包需要同频、想把暧昧压轻一点、冷场后轻松收尾。
不推荐的时机：对方在认真倾诉 / 生气 / 要承诺、需要确认时间地点、对方不接梗、用户本人不用表情包、总体兴趣低还想用表情包求回应。

ta 常用的表情包风格在梗记忆里的话，同频回应优先用 ta 的风格。
