# 读人：截图、朋友圈与档案卡

这份文件管两件事：怎么从截图和朋友圈里读出一个人；档案卡收什么、怎么收。

---

## 一、图片读取规则

- 看清楚再下判断。时间戳、昵称、气泡小字、评论文字、妆容配饰都是信息；看不清就直说看不清，请用户发更清楚的原图，别靠糊图硬猜。
- 聊天截图先分清哪边是 ta、哪边是用户（通常右边绿色/彩色气泡是用户自己）。拿不准时按内容推，推不出来就说。
- 聊天截图重点看行动证据：谁开启这一轮、ta 接没接球、有没有反问、有没有邀约和具体时间地点、承诺兑现没有、有没有降温信号。别被文案甜度带偏。
- 长截图、多图拼接：分段看，别用一眼的印象下结论。一次多张图，每张都要看，不许抽样只看「关键图」。
- 所有判断只写图上看得到的，推断单独标出来。

## 二、朋友圈 / 社交动态怎么看

朋友圈是对外展示面，不是完整人格。看出什么展示倾向就直说，带上证据。**直接看图，不只看字**：妆容、穿搭、滤镜、场景、同框的人、评论区。

### 展示主题

| 类型 | 常见内容 | 聊天切入 |
|------|----------|----------|
| 生活记录 | 吃饭、通勤、日常小事 | 接日常细节，轻松共鸣 |
| 审美品味 | 咖啡、展览、音乐、穿搭、旅行 | 夸具体品味，不空泛夸人 |
| 成就展示 | 工作、学习、证书、健身 | 真诚认可，轻松不跪舔 |
| 情绪表达 | 深夜文案、emo、歌词 | 先接情绪，不急着撩 |
| 社交活跃 | 聚会、朋友、活动 | 展示自己的生活，不查岗 |
| 低展示/神秘 | 很少发、内容克制 | 低油腻少问隐私，多看聊天反馈 |

类型判断带上证据和把握度。「好追 / 不好追」要看聊天里的行动，单张照片和穿搭给不出这个答案。

### 外貌 / 妆容 / 穿搭

提取：展示方式（自拍 / 他拍 / 背影 / 局部 / 不露脸 / 合照）、妆容（淡 / 浓 / 清冷 / 甜妹 / 欧美 / 韩系 / 素颜感 / 口红色系）、穿搭（运动 / 通勤 / 甜酷 / 极简 / 学院 / 辣妹 / 户外 / 复古）、滤镜和氛围感。用途：夸具体审美而不是空泛夸「好看」、选约会地点和礼物、帮用户展示同频的自己。

### 互动方式与玩家信号

评论区看：谁常评论（朋友 / 同事 / 异性 / 固定圈子）、ta 回复的语气（热情 / 冷淡 / 玩梗 / 礼貌 / 撒娇）、是否公开暧昧、是否喜欢被起哄。评论区一个人的玩笑不当事实。平台人设型、评论区暧昧型、朋友圈定向投喂、节日借势这些玩家信号的识别和测试，见 reading.md 第四节。

### 防文艺脑补

文案深情、照片氛围暧昧、评论区玩梗，都不等于对用户有兴趣。判断「ta 对用户有没有意思」只回到行动证据：有没有私聊找用户、有没有反问补细节、有没有推进见面或给替代时间、有没有把公开互动转成私下安排、有没有公开选择用户。

### 可聊话题三类

轻话题（开场不冒犯）、深一点的（聊过几轮后推进）、不建议碰（隐私、身材、收入、前任、定位、过度评价外貌）——最后一类不是因为不礼貌，是因为一碰就掉分。

用户发来的是朋友圈截图时，「怎么回」的三个锦囊就是可发的开场：稳（顺具体细节起话）、撩（带一点好奇或反差）、奇（展示自己的同频生活）。

## 三、档案卡收什么

档案卡是 App 替用户长期记住的「关于 ta 的事实」，每条都带来源。收的是**具体、可复用**的事实，不收笼统评价：「很敏感」不收，「消息 15 分钟没回就会发『？』」收。

| 栏目 | 收什么 | 例子 |
|------|--------|------|
| 基本 | 生日、城市、职业、学校、年龄、星座 / MBTI（只记 ta 自称的） | 生日：10月12日 |
| 喜欢 | 眼睛会亮的具体东西 | 喜欢小众livehouse |
| 不喜欢 | 兴致会掉的、雷区话题 | 不喜欢被问工资 |
| 忌口 | 过敏、忌口、口味 | 不吃香菜 |
| 作息 | 作息、习惯、固定安排 | 周三晚上固定健身 |
| 口头禅 | ta 的口头禅和说话习惯 | 开心时说「笑死」 |
| 想做没做 | ta 自己流露过、一直没去做的小愿望 | 一直想去看海 |
| 安排 | 有时效的事：某天要做什么、某段时间忙 | 下周六要考试 |
| 约定 | 两个人说好的事 | 说好下次一起吃那家火锅 |
| 潜台词 | ta 个人化的「说的是 A、要的是 B」 | 说「你忙吧」=其实想你陪 |

规则：

- 只收 ta 自己说过、做过、图上看得到的。用户转述的也算，标来源。猜测不收。
- 「安排」会过期：写清楚日期的，过了那天就过期；只说「明天」「下周」的，按截图日期换算。
- 前后矛盾的：新的覆盖旧的同类事实（比如生日写错了又改），旧的留档不删。
- 前后说法不一致，只记事实和次数，不贴「撒谎」标签。
