# Slang glossary (English)

Sections: A fresh & in use · B everyday (not really slang anymore) · C aging · D dead / dates you · E special entries · F maintenance

How to use: one row per term. "Status" decides whether the user can say it (see memes.md):
fresh / in use = fine; everyday = say it freely; aging = ironic use only; dead = don't; careful = read the note.
"Checked" is the last month the entry was reviewed; refresh anything older than 12 months before using it.

## F. Maintenance

This file is both the app's slang scanner and the vibe check's blacklist for English chats: rows in A / C / E and the list in B are matched against the other person's messages; everything in D is a hard fail in copyable messages; C, plus E rows marked "careful", are warnings; E rows marked "never" are fails. Editing this file changes the app — no code changes needed.

When adding or re-checking a term, add or update a row in A:

```
| {slang} | {meaning / use} | {tone / when} | {fresh / in use / careful} | {YYYY-MM} |
```

- Write the current year-month in "Checked". When something ages, move it to C or D instead of deleting it.
- Only general slang goes here. Their personal words and inside jokes belong in that person's slang memory in the app.
- If only one sketchy source mentions a term, mark it "careful" until a second source confirms it.
- Slang has a half-life of 6-12 months; review the whole file about twice a year.
