# 🀄 电子军师 v6.0.0 · 朱批

从最底层重做的一版。问答策略回到中心，界面有了自己的样子。

![主界面](../../assets/v6-home.jpg)

## What's new

- **The strategy doctrine is the brain again.** Every turn sends the full `references/` playbook (core, voice, memes, reading, strategy; dating and profile on demand). v5's local decision engine — which had quietly replaced the doctrine with a thin prompt and forced all reply options into variants of one tactic — is gone.
- **Positive, opinionated prompting.** The counselor takes the user's side, commits to calls, and states confidence as 「八成 / 大概率」 plus a test. No moral lectures, no stacks of "don't" rules; style bans live in the deterministic voice lint instead.
- **稳 / 撩 / 奇 plans + five nerve gears.** Nerve shifts the oiliness cap, the direction of the 奇 plan, and which plan gets recommended — never the read itself.
- **Anti-player mode for both genders.** Clear-eyed mode stops you from over-investing in a 海王 or a 海后 with the same evidence rules.
- **Optional gender for ta and for you**, so pronouns and the 追女生 / 追男生 playbooks match.
- **「朱批」design language.** Rice-paper and ink-night themes, vermilion annotations drawn on the partner's own words, stamped plan cards, a 「荐」 seal, a double-ruled 军令 card, and a new seal icon.
- **Memory that sticks.** An always-on dossier (birthday, likes, taboos, catchphrases…), ta's meme memory, a searchable archive of old chats and screenshots, and real dates / festivals in every prompt.
- **Learns from what actually happened.** One-tap 「后来怎样」, tactic records per seal, phrases that went cold, and your real texting style.
- **Connections.** Codex and Claude Code reuse your logins (Codex bundled inside ChatGPT.app is found automatically, even when launched from Finder); Claude API via the official SDK (default Claude Opus 5.5, prompt caching, server-side refusal fallback); DeepSeek / GLM / any OpenAI-compatible endpoint; offline demo.
- **v5 data migrates automatically** on first launch; keychain API keys keep working.

## Upgrading

Install over v5. Your profiles, chats, screenshots, and organized screenshot memories move into the new database on first launch; the old files stay untouched. The v5 code lives on at tag `v5-final`.
