前五份放在最前面、顺序固定，Claude API 会把它们整段缓存；后两份按需追加。

## 一轮是怎么跑的

1. **扫梗**（服务端，不花 token）：对方的话对一遍梗词典，命中的条目交给军师直接采信，同时画成原话上的朱批。
2. **分诊**：按关键词判断是日常、情绪、冲突、邀约、玩梗还是拉扯，决定要不要带上约会模块。
3. **装配**：问答策略 + 此刻（真实日期、临近节日、ta 的生日）+ 当前档案（阶段、本次油腻上限、胆量、清醒提醒、性别）+ 档案卡 + ta 的梗 + 打法记忆 + 你的风格 + 兴趣走势 + 最近几轮 + 按问题找回的旧资料。
4. **生成**：模型按输出契约写 judge 块（读局）、锦囊（reply 围栏）、推荐、避坑，需要时写军令、旁白、表情包建议、清醒拦截。
5. **人话门禁**：每个锦囊跑一遍确定性检查。句尾句号、连发感叹号直接修；禁词、过气梗、太长的，交给军师再改一稿；改完还不过，就在卡片上标出卡在哪。
6. **记下来**：兴趣读数进走势，ta 用过的梗进梗记忆，这轮的原话进素材库。

## 这一版刻意保持的

- 原来的整套打法：阶段与油腻上限、四维兴趣、清醒提醒（反舔狗）硬阈值、海王 / 海后置信度、拉扯 0-3、追女生 / 追男生类型、痞 / 乖气质、稳 / 会撩 / 第三种三个方案、推荐加「别这样回」、帮我改的三档结论、约会的两条通道。
- 先扫梗、再过人话门禁这两条底线。
- 先记事件、再升规则：聊冷的原句一次就进「别再给」，接住的说法重复出现才算稳定打法。

## 这一版微调的

- **规则用正面的写法**：告诉模型该怎么做——站在用户这边、敢下判断、有态度、会接情绪，少用「不要 X、不要 Y」。一堆禁令只会把模型压成一个谨慎中立、谁也不得罪的样子，在情感这件事上没人需要这种军师。拿不准的地方，用「八成」「大概率」这样的把握度加一个验证办法来说，不和稀泥。
- **不加道德评判**：用户要的是打法。风格上的禁区（长辈腔、过气梗）交给代码里的人话检查去拦，不写进提示堆成禁令。
- **三个锦囊改名为稳 / 撩 / 奇**：第三个由胆量决定方向，从展示自己一路到直接约、打直球。
- **胆量五档**直接作用在打法上：调整油腻上限、「奇」的方向和推荐倾向；判断照实给。
- **男生女生都照顾到**：可选写性别，写了用对他 / 她、选对追女生 / 追男生那张表；判断标准不因性别变。
- **读局可视化**：梗和语气信号用朱笔批在原话上，兴趣、海王指数画成刻度。

## 英文那一套（v6.1）

英文聊天用 `references/en/` 里的另一套策略。它是按英语圈的聊天和约会文化重新写的，不是翻译：阶段是 talking stage → dating（默认不排他）→ DTR，而不是暧昧 → 追求 → 告白；句尾句号同样显冷，但一个「!」显得热情；约人讲究约一次、说清楚，把球交给对方，而不是锲而不舍地「追」；早期同时在用约会 App 不算海王信号，看的是模式；节日是情人节、Galentine's、cuffing season、感恩节；过气梗是 on fleek、YOLO、bae。

两套**不会同时进上下文**。每个档案有自己的聊天语言（默认跟随界面），决定这一轮装哪一套、用哪个梗词典和哪套人话检查。界面语言和聊天语言不一样时，只多一行说明：解说用界面语言写，锦囊用聊天语言写。

判断标准两边一样：看行动不看甜话，站在用户这边，不加道德评判，油腻上限和清醒阈值不分男女。

## 为什么 v6 推倒重来

v5 在问答策略外面套了一层本地「决策引擎」：九维信念、体制切换的世界模型、1252 参数的时序卷积网络、决策网络可视化。问题出在两处：

1. **它替代了问答策略。** 发给模型的是引擎那段很薄的提示，`references/` 里的打法只用来显示标签。引擎还要求「几个文案必须是同一策略的轻微变体」，把「稳妥 / 会撩 / 第三种拉开差距」的核心打法废掉了。
2. **它学不动。** 每个人的真实结果通常只有几条到几十条，撑不起那么多参数。结果就是用看起来很精密的数字，对「周六别放我鸽子哈哈」给出「你是想先静一静还是晚点再聊」这样的建议。

v6 把判断还给最擅长读聊天的模型，按你的问答策略去读、去答；把本机的力气花在模型做不好、或者不该做的事上：确定性的扫梗和人话检查、真实日期、长期记住 ta 的事、从真实结果里统计打法战绩。每一样都能在界面上看到、改掉。
