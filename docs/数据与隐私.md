# 数据与隐私

## 存在哪

全部在你电脑上的 `~/.dianzi-junshi/`（可以用环境变量 `DIANZI_JUNSHI_HOME` 改位置）：

```text
junshi.db            SQLite（WAL）：档案、对话、档案卡、ta 的梗、素材库、结果记录、导入任务
people/<编号>/img/   截图原件
settings.json        连接设置（不含 API Key）
```

- API Key 只存在系统凭据库：macOS 钥匙串、Windows 凭据管理器、Linux Secret Service。
- 删除一个档案会一起删掉它的对话、截图、档案卡、素材和结果记录。
- 同一张图传两次只存一份（按内容哈希）。
- 没有云同步，也不会把任何东西发给仓库维护者。

## 发给谁

每一轮，你选的那个 AI 连接会收到：问答策略、当前档案、档案卡、ta 的梗、打法记忆、最近几轮的摘要、按问题找回的几段旧资料，以及这次贴的内容和截图。其余内容不会发出去。

- **Codex / Claude Code**：在只读沙箱里运行，工作目录是这个人的数据目录；每次都是临时会话，不保留历史。
- **Claude API / DeepSeek / GLM / 自定义接口**：按各自的服务条款处理你发过去的内容，请一并阅读。
- **本机语义检索**（可选）：只连本机的 Ollama（`127.0.0.1:11434`），不出你的电脑。
- **演示模式**：完全离线。

## 本机服务

后端只监听 `127.0.0.1`，并且只接受来自本机页面的请求：Host 和 Origin 不是本机的一律拒绝，挡住其他网站借你的浏览器访问本机端口，也挡住 DNS rebinding。

## 从 v5 搬家

第一次启动 v6 时，`~/.dianzi-junshi/partners/` 下的旧档案、对话、截图，以及 `memory.sqlite3` 里已经整理好的截图记忆，会搬进新的 `junshi.db`。旧文件原样留着，确认没问题后可以自己删掉。每个旧档案只搬一次。
