# 设计语言：朱批

旧时先生批改文章，用朱砂在原文旁边划线、写批语。电子军师读你的聊天，做的是同一件事：在 ta 的原话上划线点出梗和语气，再把出的主意盖上印交给你。

整套界面只有三种颜色角色：

| 角色 | 亮色「宣纸」 | 暗色「墨夜」 | 用在哪 |
| --- | --- | --- | --- |
| 纸 | `#f3eee3` 宣纸，卡片 `#fbf8f1` | `#141311`，卡片 `#1f1d1a` | 底色、卡片 |
| 墨 | `#1c1a17` | `#ece5d6` | 正文、标题、「稳」印 |
| 朱 | `#c8372d` 朱砂 | `#e2553f` | 军师的笔：批注、「撩」印、「荐」、主按钮、清醒拦截 |

另外两种颜色各有专职：**黛蓝** `#2f4c5c` 只给「ta」（ta 的原话左边那条竖线、「奇」印、旁白）；**青玉** `#3d7a5f` 只表示「过了」（人话过关、接住了）。

全部颜色都是 [`app/web/styles/tokens.css`](../app/web/styles/tokens.css) 里的变量，暗色主题重新定义同一组变量。

## 字

- **宋体**（Songti SC / Noto Serif SC）：标题、判断、锦囊名、印章，是军师说话的声音。
- **楷体**（Kaiti SC / KaiTi）：朱批、锦囊下面那句「为什么」，像手写的批语。
- **黑体**（PingFang SC / 微软雅黑）：正文和可复制的气泡，因为你要把它原样发出去。

全部用系统字体，不打包字体文件，离线也一样。

## 元件

- **印**：白文印（红底白字）用于稳 / 撩 / 奇；朱文印（白底红框红字）用于「荐」。毛边和飞白来自一次定义的 SVG 滤镜，每个印都像真盖上去的。品牌是四字印「电子军师」，按传统从右列读起。
- **朱批**：原话里的梗、语气信号用朱色波浪线划出来，右上角标圈号，下面用楷体写批语。
- **锦囊**：卡片顶上一道印色（稳是墨、撩是朱、奇是黛），里面的气泡就是你要发的字；推荐的那张斜盖一个「荐」。
- **别这样回**：错误示范用朱笔删除线划掉，像先生改作文。
- **军令**：上下双线框，像一份公文——回复间隔、消失建议、拉扯动作、看反馈。
- **醒**：清醒提醒触发时出现的朱框卡片。
- **胆量刻度**：五格，越敢颜色越热，从灰、黛、墨、赭一路到朱；档名用楷体写。
- **稿纸**：输入框是一张方格稿纸。

## 语气

界面文字和锦囊一样守人话门禁：短句、口语、不端着。「出锦囊」「拆一下」「过一眼」「看看有没有戏」，而不是「提交」「分析」。

## 可用性

- 亮色 / 暗色跟随系统，设置里可以手动选。
- 键盘：Enter 发送、Shift+Enter 换行，中文输入法选字时的回车不会误发；Esc 关闭抽屉和弹窗；焦点有朱色描边。
- 窄屏：名册和档案卡变成左右抽屉，锦囊改成单列。
- 尊重「减少动画」设置。
